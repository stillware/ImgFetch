# Documentation

Index of every ImgFetch document, with reading paths for users, contributors and reviewers.

Applies to: ImgFetch 1.1.0
Last verified: 2026-10-22

## Start here

For a user:

1. [README.md](../README.md) for what ImgFetch does, how to install it and the quick start.
2. [user-guide.md](user-guide.md) for task based help with downloads, screenshots, the editor and settings.
3. [limitations.md](limitations.md) for known limits and workarounds.
4. [../PRIVACY.md](../PRIVACY.md) for what data ImgFetch handles and where it stays.

For a contributor:

1. [README.md](../README.md) for the product overview and project structure summary.
2. [../CONTRIBUTING.md](../CONTRIBUTING.md) for setup, checks, conventions and the pull request process.
3. [architecture.md](architecture.md) for components, messages, storage and error handling.
4. [project-structure.md](project-structure.md) for the annotated file tree and naming rules.
5. [build.md](build.md) and [tests/README.md](tests/README.md) for build steps and test suites.
6. [decisions/README.md](decisions/README.md) for the architecture decisions behind the current design.

For a security reviewer:

1. [../SECURITY.md](../SECURITY.md) for supported versions and how to report a vulnerability.
2. [security-model.md](security-model.md) for the threat model, mitigations and accepted risks.
3. [permissions.md](permissions.md) for every permission and host permission, and why each one exists.
4. [../PRIVACY.md](../PRIVACY.md) for the data handling claims to check against the code.
5. [tests/README.md](tests/README.md) for the security suite and how to run it.
