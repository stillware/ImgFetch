# History Index

Index to the historical build and audit records kept with ImgFetch.

Applies to: ImgFetch 1.1.0
Last verified: 2026-10-21

These files are historical records. They are kept unchanged, exactly as they were written at the time, so they describe the product as it was in that round. Shortcuts, permissions, settings, and test counts in them may no longer match the current product.

For current behavior, see the [root README](../../README.md) and the [user guide](../user-guide.md).

| File | What it records |
|---|---|
| `01-initial-build-plan.md` | The first build plan, written before the initial build. It records the planned feature matrix and tiers for the original version. |
| `02-audit-round-1-fixes.md` | Audit round 1. It records the findings from the first independent audit and the fix, rejection, or deferral recorded for each one. |
| `03-audit-round-2-fixes.md` | Audit round 2. It records the findings from the second audit, including the restart recovery and private network guard fixes. |
| `04-audit-round-3-fixes.md` | Audit round 3. It records the findings from the third audit round, with the status and proving test for each finding. |
| `05-audit-round-4-fixes.md` | Audit round 4. It records the fixes and the evidence for them, including the findings that were kept unchanged by owner decision. |

No file in this folder, other than this index, is edited after its round closes.
